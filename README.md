# Portfolio Website

A modern, animated portfolio website built with React, Tailwind CSS, and Framer Motion.

## Tech Stack

- **Frontend**: React 18
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Build Tool**: Vite
- **Theme**: Dark mode support with custom context

## Features

✨ **Smooth Animations** - Scroll animations, hover effects, and floating elements
🌙 **Dark Mode** - Seamless theme switching with localStorage persistence
📱 **Responsive Design** - Mobile-first design that works on all devices
🎨 **Modern UI** - Gradient effects, glassmorphism, and smooth transitions
⚡ **Fast Performance** - Built with Vite for instant HMR

## Components

- **Header** - Navigation bar with theme toggle
- **Hero** - Main landing section with animated portrait and CTA buttons
- **About** - Personal bio and skills section
- **Projects** - Showcase of featured projects
- **Footer** - Contact and social links

## Installation

```bash
yarn install
```

## Development

```bash
yarn dev
```

The site will open at `http://localhost:3000`

## Build

```bash
yarn build
```

## Preview

```bash
yarn preview
```

## Customization

- Edit component colors in `tailwind.config.js`
- Modify animation timing in individual components
- Update personal information in components
- Add your own project data in `Projects.jsx`

Enjoy! 🚀
